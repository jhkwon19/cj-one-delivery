# CJ O-NE 배송조회

Home Assistant에서 CJ대한통운(CJ O-NE) 배송 현황을 조회하고, 배송 상태 변경을 자동화에
활용할 수 있는 커스텀 통합구성요소입니다.

휴대폰 문자 인증으로 계정을 등록하면 해당 전화번호 기준의 배송 목록을 주기적으로
조회합니다. **새로운 배송건이 감지되면 운송장 번호별로 전용 기기(device)와 센서가
자동으로 생성**되고, 배송완료 후 설정한 보관 일수가 지나면 해당 기기와 센서가
자동으로 삭제됩니다.

## 주요 기능

- 휴대폰 번호와 문자 인증번호를 이용한 설정 플로우
- 새로운 배송건 감지 시 운송장 번호별 기기/센서 자동 생성
- 배송완료 후 보관 일수가 지나면 기기/센서 자동 정리
- 진행중/배송완료 목록 요약 센서 제공
- 배송 상태 변경 이벤트 센서 제공
- access token 만료 시 refresh token으로 자동 갱신
- 완료된 배송은 상세 정보를 캐시해 불필요한 API 재조회를 하지 않음
- 조회 주기와 배송완료 보관 일수 옵션 설정
- Home Assistant 자동화와 TTS 방송에 활용 가능

## 현재 버전

- `v0.3.0`

## 설치

### HACS 사용자 저장소로 설치

1. HACS를 엽니다.
2. 우측 상단 메뉴에서 `Custom repositories`를 선택합니다.
3. Repository에 아래 주소를 입력합니다.

```text
https://github.com/jhkwon19/cj-one-delivery
```

4. Category는 `Integration`을 선택합니다.
5. 추가 후 `CJ O-NE 배송조회`를 설치합니다.
6. Home Assistant를 재시작합니다.

### 수동 설치

`custom_components/cj_one_delivery` 폴더를 Home Assistant 설정 디렉터리의
`custom_components` 아래에 복사합니다.

```text
config/
└─ custom_components/
   └─ cj_one_delivery/
```

복사 후 Home Assistant를 재시작합니다.

## 설정

1. Home Assistant에서 `설정` > `기기 및 서비스`로 이동합니다.
2. `통합구성요소 추가`를 누릅니다.
3. `CJ O-NE 배송조회`를 선택합니다.
4. 휴대폰 번호를 입력합니다.
5. 문자로 받은 인증번호를 입력합니다.

등록이 완료되면 배송 목록이 자동으로 조회되고 센서가 생성됩니다.

## 옵션

통합구성요소의 `구성` 또는 `옵션` 메뉴에서 아래 값을 설정할 수 있습니다.

- `조회 주기(분)`: 5~180분
- `배송완료 보관 일수`: 1~90일 (기본 7일)

배송완료 후 설정한 보관 일수가 지나면 해당 운송장의 기기와 센서가 자동으로
삭제됩니다. 완료된 배송은 보관기간 동안에도 상세 정보를 다시 조회하지 않고
캐시된 값을 그대로 보여줍니다.

## 생성되는 센서

### 요약 센서 (통합구성요소 메인 기기 아래)

- `배송 요약`
- `진행중 배송`
- `배송완료`
- `최근 배송 이벤트`

`최근 배송 이벤트` 센서는 배송 상태, 위치, 시간이 바뀌었을 때 자동화 트리거로 쓰기
좋은 문장을 상태값으로 제공합니다.

`진행중 배송`과 `배송완료` 센서의 `deliveries` 속성에는 각 배송의 운송장 번호, 상품명,
상태, 최근 위치, 최근 일시가 요약되어 저장됩니다. 배송기본정보와 배송상세 타임라인은
각 운송장 기기의 `배송 상세` 센서에서 확인합니다.

### 운송장별 기기와 세부 센서

새로운 배송건이 감지되면 운송장 번호마다 `택배 xxxx-xxxx-xxxx` 형태의 기기가
자동으로 생성되고, 그 아래 다음 세부 센서가 함께 생성됩니다.

- `상태`
- `상품명`
- `운송장 번호`
- `보내는 분`
- `받는 분`
- `최근 위치`
- `최근 일시`
- `배송기사`
- `배송 상세`

배송이 완료된 후 옵션에서 설정한 보관 일수가 지나면 해당 운송장의 기기와 센서
전체가 자동으로 제거됩니다. 기기와 엔티티가 운송장 하나에 고정되므로, 상태 변경
히스토리를 보면 그 택배 하나의 배송 과정만 정확히 나타납니다.

## 대시보드 활용

이 통합구성요소는 운송장 번호별로 Home Assistant 기기를 나누어 생성합니다. 새 배송이
잡히면 대시보드에도 자동으로 새 기기가 나타나므로, `자동 엔티티(auto-entities)` 카드나
기기 목록을 활용해 현재 추적 중인 배송을 한눈에 볼 수 있습니다. 특정 운송장을 고정
카드에 배치하고 싶다면 해당 기기의 세부 센서를 `엔티티` 카드에 담으면 됩니다.

예를 들어 하나의 운송장 기기에 대해 아래 센서를 한 카드에 배치할 수 있습니다.

- `상태`
- `상품명`
- `운송장 번호`
- `최근 위치`
- `최근 일시`
- `배송기사`

`배송 상세` 센서는 상태값으로 상세 내역 존재 여부를 표시하고, 속성에 배송기본정보와
배송상세 타임라인을 저장합니다. 모든 세부 센서는 속성에 `tracking_number`(운송장
번호)를 포함하므로, 자동화나 히스토리 그래프에서 어떤 택배의 값인지 항상 구분할 수
있습니다.

## 자동화 예시

배송 상태가 바뀔 때 스피커로 방송하려면 `최근 배송 이벤트` 센서를 트리거로 사용하면
됩니다. 아래 예시는 `tts.speak`와 `edge_tts`를 사용하는 경우입니다.

```yaml
alias: "[택배] CJ O-NE 배송 상태 변경 알림"
description: ""
triggers:
  - trigger: state
    entity_id:
      - sensor.cj_o_ne_baesongjohoe_coegeun_baesong_ibenteu
conditions:
  - condition: template
    value_template: >
      {{ trigger.to_state is not none
         and trigger.to_state.state not in ['unknown', 'unavailable', '배송 변경 이벤트 없음']
         and state_attr('sensor.cj_o_ne_baesongjohoe_coegeun_baesong_ibenteu', 'announcement') not in [none, ''] }}
actions:
  - action: tts.speak
    target:
      entity_id: tts.edge_tts_2
    data:
      cache: true
      media_player_entity_id:
        - media_player.geosil_mini
        - media_player.anbang_mini
      message: "{{ state_attr('sensor.cj_o_ne_baesongjohoe_coegeun_baesong_ibenteu', 'announcement') }}"
      language: ko-KR
mode: single
```

실제 `entity_id`는 Home Assistant에서 생성된 엔티티 ID에 맞게 바꿔야 합니다.

### 방송 문구 형식

`최근 배송 이벤트` 센서의 `announcement` 속성에는 방송에 바로 사용할 수 있는 문장이
저장됩니다.

새 배송건이 감지되면 아래 형식으로 제공됩니다.

```text
{상품명} 배송이 새로 확인되었습니다. 현재 {최근위치}에서 {상태} 상태입니다.
```

기존 배송건의 상태, 위치, 시간이 바뀌면 아래 형식으로 제공됩니다.

```text
{상품명} 배송이 {최근위치}에서 {상태} 상태로 변경되었습니다.
```

예시:

```text
led adapter 배송이 대전Hub에서 간선상차 상태로 변경되었습니다.
```

상품명이 없으면 `택배`로 대체되고, 최근 위치가 없으면 위치 문구는 생략됩니다.

## 업데이트 주기

배송 정보는 기본 30분 주기로 갱신됩니다. 옵션에서 5~180분 사이로 변경할 수 있습니다.

```text
통합구성요소 로드 시 1회 조회
이후 30분마다 자동 조회
```

상태, 최근 위치, 최근 일시 중 하나가 바뀌면 `최근 배송 이벤트` 센서가 갱신됩니다.

access token이 만료된 경우에는 refresh token으로 토큰을 갱신한 뒤 원래 배송조회 요청을
한 번 재시도합니다. refresh token까지 만료되면 재인증이 필요합니다.

## 참고 사항

- 이 통합구성요소는 CJ O-NE 앱과 동일한 계정 기준의 배송 목록을 조회합니다.
- 배송 상태와 상세 정보는 CJ대한통운 서버 응답에 따라 표시됩니다.
- 처음 등록 직후 기존 배송건은 기준값으로 저장되며, 이후 변경부터 최근 배송 이벤트로
  반영됩니다.
- 진행중 배송은 건수 제한 없이 전부 기기/센서로 생성됩니다.
- 배송완료 건은 완료 시점 기준 설정한 보관 일수 동안만 기기/센서가 유지되고,
  이후에는 자동으로 정리됩니다.
- `v0.2.4` 이하 슬롯 방식 버전에서 업그레이드한 경우, 기존 슬롯 기반 엔티티는
  다음 조회 시점에 자동으로 정리됩니다(수동 정리 불필요).
