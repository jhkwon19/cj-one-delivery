# CJ O-NE 배송조회

Home Assistant에서 CJ대한통운(CJ O-NE) 배송 현황을 조회하고, 배송 상태 변경을 자동화에
활용할 수 있는 커스텀 통합구성요소입니다.

휴대폰 문자 인증으로 계정을 등록하면 해당 전화번호 기준의 배송 목록을 주기적으로
조회합니다. 진행중 배송은 최대 3개 슬롯, 배송완료 건은 최근 5개 슬롯으로 나누어
센서를 생성하므로 기본 대시보드 카드만으로도 배송 정보를 배치할 수 있습니다.

## 주요 기능

- 휴대폰 번호와 문자 인증번호를 이용한 설정 플로우
- 진행중 배송 조회
- 배송완료 최근 배송 조회
- 슬롯별 세부 센서 생성
- 배송 상태 변경 이벤트 센서 제공
- access token 만료 시 refresh token으로 자동 갱신
- 조회 주기와 슬롯 개수 옵션 설정
- Home Assistant 자동화와 TTS 방송에 활용 가능
- 별도 커스텀 Lovelace 카드 불필요

## 현재 버전

- `v0.2.1`

## 설치

### HACS 사용자 저장소로 설치

1. HACS를 엽니다.
2. 우측 상단 메뉴에서 `Custom repositories`를 선택합니다.
3. Repository에 아래 주소를 입력합니다.

```text
https://github.com/jhkwon19/cj-one-delivery
```

4. Category는 `Integration`을 선택합니다.
5. 추가 후 `CJ O-NE 배송조회`를 설치합니다.
6. Home Assistant를 재시작합니다.

### 수동 설치

`custom_components/cj_one_delivery` 폴더를 Home Assistant 설정 디렉터리의
`custom_components` 아래에 복사합니다.

```text
config/
└─ custom_components/
   └─ cj_one_delivery/
```

복사 후 Home Assistant를 재시작합니다.

## 설정

1. Home Assistant에서 `설정` > `기기 및 서비스`로 이동합니다.
2. `통합구성요소 추가`를 누릅니다.
3. `CJ O-NE 배송조회`를 선택합니다.
4. 휴대폰 번호를 입력합니다.
5. 문자로 받은 인증번호를 입력합니다.

등록이 완료되면 배송 목록이 자동으로 조회되고 센서가 생성됩니다.

## 옵션

통합구성요소의 `구성` 또는 `옵션` 메뉴에서 아래 값을 설정할 수 있습니다.

- `조회 주기(분)`: 5~180분
- `진행중 배송 슬롯 개수`: 1~3개
- `배송완료 슬롯 개수`: 1~5개

엔터티 레지스트리 안정성을 위해 최대 슬롯 센서는 미리 생성됩니다. 옵션에서 선택한 개수
밖의 슬롯은 `사용 안 함` 상태로 표시됩니다.

## 생성되는 센서

### 요약 센서

- `배송 요약`
- `진행중 배송`
- `배송완료 최근 배송`
- `최근 배송 이벤트`

`최근 배송 이벤트` 센서는 배송 상태, 위치, 시간이 바뀌었을 때 자동화 트리거로 쓰기
좋은 문장을 상태값으로 제공합니다.

`진행중 배송`과 `배송완료 최근 배송` 센서의 `deliveries` 속성에는 각 배송의 슬롯 번호,
상품명, 상태, 운송장 번호, 최근 위치, 최근 일시만 요약해서 저장됩니다. 배송기본정보와
배송상세 타임라인은 각 슬롯의 `배송 상세` 센서에서 확인합니다.

### 진행중 배송 슬롯

진행중 배송은 최근 일시 기준 최대 3개 슬롯으로 표시됩니다. 표시 개수는 옵션에서
1~3개 사이로 조정할 수 있습니다.

- `진행중 배송 슬롯 1`
- `진행중 배송 슬롯 2`
- `진행중 배송 슬롯 3`

각 슬롯 아래에는 다음 세부 센서가 생성됩니다.

- `상태`
- `상품명`
- `운송장 번호`
- `보내는 분`
- `받는 분`
- `최근 위치`
- `최근 일시`
- `배송기사`
- `배송 상세`

### 배송완료 슬롯

배송완료 건은 최근 완료일 기준 최대 5개 슬롯으로 표시됩니다. 표시 개수는 옵션에서
1~5개 사이로 조정할 수 있습니다.

- `배송완료 슬롯 1`
- `배송완료 슬롯 2`
- `배송완료 슬롯 3`
- `배송완료 슬롯 4`
- `배송완료 슬롯 5`

각 슬롯에는 진행중 배송 슬롯과 같은 세부 센서가 생성됩니다.

## 대시보드 활용

이 통합구성요소는 배송 슬롯을 Home Assistant 기기처럼 나누어 생성합니다. 대시보드에서는
기본 `엔티티` 카드나 `섹션`을 사용해 원하는 슬롯의 세부 센서를 배치하면 됩니다.

예를 들어 `진행중 배송 슬롯 1`에 대해 아래 센서를 한 카드에 배치할 수 있습니다.

- `상태`
- `상품명`
- `운송장 번호`
- `최근 위치`
- `최근 일시`
- `배송기사`

`배송 상세` 센서는 상태값으로 상세 내역 존재 여부를 표시하고, 속성에 배송기본정보와
배송상세 타임라인을 저장합니다.

배송이 없는 슬롯은 세부 센서 상태값이 `없음`으로 표시되고, `is_empty` 속성이 `true`가
됩니다.

## 자동화 예시

배송 상태가 바뀔 때 구글 스피커로 방송하려면 `최근 배송 이벤트` 센서를 트리거로
사용하면 됩니다.

```yaml
alias: CJ O-NE 배송 상태 방송
trigger:
  - platform: state
    entity_id: sensor.cj_o_ne_choegeun_baesong_ibenteu
condition:
  - condition: template
    value_template: >
      {{ trigger.to_state.state not in ['배송 변경 이벤트 없음', 'unknown', 'unavailable'] }}
action:
  - service: tts.google_translate_say
    data:
      entity_id: media_player.google_speaker
      message: "{{ trigger.to_state.state }}"
```

실제 `entity_id`는 Home Assistant에서 생성된 엔티티 ID에 맞게 바꿔야 합니다.

## 업데이트 주기

배송 정보는 기본 30분 주기로 갱신됩니다. 옵션에서 5~180분 사이로 변경할 수 있습니다.

```text
통합구성요소 로드 시 1회 조회
이후 30분마다 자동 조회
```

상태, 최근 위치, 최근 일시 중 하나가 바뀌면 `최근 배송 이벤트` 센서가 갱신됩니다.

access token이 만료된 경우에는 refresh token으로 토큰을 갱신한 뒤 원래 배송조회 요청을
한 번 재시도합니다. refresh token까지 만료되면 재인증이 필요합니다.

## 참고 사항

- 이 통합구성요소는 CJ O-NE 앱과 동일한 계정 기준의 배송 목록을 조회합니다.
- 배송 상태와 상세 정보는 CJ대한통운 서버 응답에 따라 표시됩니다.
- 처음 등록 직후 기존 배송건은 기준값으로 저장되며, 이후 변경부터 최근 배송 이벤트로
  반영됩니다.
- 진행중 배송이 3건을 초과하면 슬롯 센서에는 최근 일시 기준 3건까지만 표시됩니다.
- 배송완료 건은 최근 완료일 기준 5건까지만 표시됩니다.
- 기존 버전에서 생성된 엔티티가 남아 있으면 Home Assistant 엔티티 레지스트리에서
  사용하지 않는 엔티티를 정리해야 할 수 있습니다.
